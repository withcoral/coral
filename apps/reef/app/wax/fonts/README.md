# Font Assets

This directory contains the self-hosted font files of the Wax UI theme.

- `encode-sans-semi-expanded/`: Encode Sans Semi Expanded from Google Fonts.
- `dm-mono/`: DM Mono from Google Fonts.

Both font families are distributed under the SIL Open Font License 1.1.
`../theme/reset.css` names each file by a relative path, so the bundler of an app
emits it.
