Install the [desktop app](/getting-started/install-locally) or
[run a shared server](/getting-started/self-host) first.

<Steps>
  <Step title="Open the Coral UI">
    You set up everything in Coral from the Coral UI.

    - **Desktop app:** Open Coral. The app window is the Coral UI.
    - **Shared server:** Go to `https://<coral-host>` in your browser, then sign in.
  </Step>

  <Step title="Add a provider" id="add-a-provider">
    A [provider](/guides/concepts#providers) gives your agents access to a
    service, such as GitHub or Linear. Your agents can only call the providers
    in your workspace. Only [workspace owners](/guides/concepts#workspaces) can
    add a provider.

    Choose a provider from Coral's catalog, or add your own from an MCP server
    or an OpenAPI document.

    A new provider starts with a default [policy](/guides/concepts#tool-policy).
    Tools that read data run without approval. Other tools need
    approval. Workspace owners can change the policy.
  </Step>

  <Step title="Connect your agent" id="connect-an-mcp-client">
    Connect your agent to Coral once, and it can use every provider in your
    [workspace](/guides/concepts#workspaces). Copy the setup for your MCP client from the Coral UI. It already
    contains your workspace's URL.
  </Step>

  <Step title="Ask a question">
    Ask your agent something that needs your provider. For example, if you've
    connected GitHub, you could ask:

    > What are my open pull requests?

  </Step>
</Steps>
