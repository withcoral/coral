Coral saves the tool-calling code that an agent writes as a custom tool.
The next agent calls that tool and does not write the code again.
This page shows the effect on real tasks.

The agent ran each task twice:

- **Without custom tools.** The agent started cold, with only the provider tools (Slack, Linear, GitHub).
- **With custom tools.** The agent could also call the custom tools that Coral saved from earlier runs.

Across the 34 tasks below, custom tools gave these results:

<CardGroup cols={4}>
  <Card title="−37% tokens" icon="coins">12.2M → 7.7M</Card>
  <Card title="−31% cost" icon="dollar-sign">&#36;9.86 → &#36;6.79</Card>
  <Card title="−29% time" icon="timer">47 min → 33 min</Card>
  <Card title="34 / 34 correct" icon="circle-check">Up from 33 / 34</Card>
</CardGroup>
