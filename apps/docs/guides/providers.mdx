Providers connect Coral to third-party data sources. Coral works with any data source that has an OpenAPI 3.0/3.1 document or a Streamable HTTP MCP server. For other data sources, see [advanced scenarios](#advanced-scenarios).

<Note>Only workspace owners can add providers.</Note>

## Adding a provider from Coral's catalog

Coral has a catalog of popular providers. To add one of these providers:

1. Go to your workspace's **Tools** page.
2. Click **Add provider**.
3. Click a provider in the list.

## Adding a provider using an OpenAPI document or MCP server URL

1. Go to your workspace's **Tools** page.
2. Click **Add provider**.
3. Click **Add custom**.

Then enter the MCP server URL, enter the URL of an OpenAPI document, or upload an OpenAPI document.

## Adding a provider using your agent

Coral has tools that manage Coral itself, so you can ask your agent to add a new provider. Your agent prepares the setup. A workspace owner must then review and publish that setup in the Coral UI.

For example, to connect Coral to ClickUp, ask your agent:

> Add a Coral provider for ClickUp

## Advanced scenarios

### Adding databases

See [database providers](/guides/providers/databases).

### Adding a provider for a service that only has a stdio MCP server

Use a bridge that runs the stdio server and exposes a Streamable HTTP endpoint. Libraries that can do this include:

- [Supergateway](https://github.com/supercorp-ai/supergateway) (Node)
- [MCP Proxy](https://github.com/sparfenyuk/mcp-proxy) (Python)
- [FastMCP](https://gofastmcp.com/getting-started/welcome) (Python)

For a complete example, see [Using the AWS MCP Server with IAM](/guides/providers/aws).

<Note>
  Self-hosted Coral denies access to private networks and loopback addresses by
  default. If you run a stdio bridge on the same host as Coral, you may need to
  update [Coral's configuration](/reference/configuration#outbound) to allow
  access.
</Note>

### Adding a provider for a service that has no OpenAPI document and no MCP server

If the service has a well-specified RESTful API, ask your agent to generate an OpenAPI document for it. Then use that document to add the provider to Coral.

Otherwise, write a small API server or MCP server that wraps the service, with [FastAPI](https://fastapi.tiangolo.com/), [FastMCP](https://gofastmcp.com/getting-started/welcome) or a similar library. Then add that server to Coral.
