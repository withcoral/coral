# PDF source

Query text, tables, images, links, annotations, form fields, and document metadata from local PDF documents using Coral SQL. Each row represents one page or one document with rich extraction via PyMuPDF.

## Prerequisites

### For plain-text PDFs (basic extraction)
- Python 3.10+ with [PyMuPDF](https://pypi.org/project/PyMuPDF/) (`pip install pymupdf`)
- [Coral](https://withcoral.com) (latest)

### For scanned PDFs (OCR support)
- Everything above, plus Python 3.11+ (OCRmyPDF requires ≥3.11, 3.12+ recommended)
- [OCRmyPDF](https://ocrmypdf.readthedocs.io/) (`pip install ocrmypdf`; installs fpdf2 + uharfbuzz for text rendering)
- System dependencies per platform:
  - **Tesseract OCR 4.1.1+** — language packs for your documents
  - **Ghostscript 9.54+** (system binary) or **pypdfium2** (Python package) — PDF rasterization
  - **fonts-noto** (recommended) — font coverage for non-Latin scripts
  - **pngquant** (optional) — lossy PNG compression
  - **unpaper** (optional) — page deskewing and cleaning
  - **jbig2enc** (optional) — monochrome image optimization

See [OCRmyPDF installation docs](https://ocrmypdf.readthedocs.io/en/latest/installation.html) for platform-specific instructions.

Note: `--ocr` mode uses [`--force-ocr`](https://ocrmypdf.readthedocs.io/en/latest/advanced.html#ocr-processing-mode) which rasterizes pages and flattens interactive objects (form fields, annotations, layers). It produces a searchable PDF but may alter the original page structure.

## Setup

### 1. Get the converter script

The source manifest reads pre-converted JSONL files, so you need the `pdf-to-jsonl.py` converter to process your PDFs.

**From a repo checkout:**
```bash
git clone https://github.com/withcoral/coral.git
cd coral
# The script is at sources/community/pdf/scripts/pdf-to-jsonl.py
```

### 2. Convert PDFs to JSONL

```bash
python sources/community/pdf/scripts/pdf-to-jsonl.py --dir ~/pdfs/
python sources/community/pdf/scripts/pdf-to-jsonl.py --files doc1.pdf doc2.pdf
python sources/community/pdf/scripts/pdf-to-jsonl.py --dir ~/pdfs/ --recursive
python sources/community/pdf/scripts/pdf-to-jsonl.py --dir ~/pdfs/ --ocr
python sources/community/pdf/scripts/pdf-to-jsonl.py --dir ~/pdfs/ --out ~/mydata/pages.jsonl --out-documents ~/mydata/documents.jsonl
```

### 3. Add the source

```bash
coral source add --file sources/community/pdf/manifest.yaml
```

### 4. Query

```sql
-- List all indexed PDFs
SELECT DISTINCT file_name FROM pdf.pages;

-- Full text of a specific document
SELECT page, text FROM pdf.pages
WHERE file_name = 'sample_report.pdf'
ORDER BY page;

-- Structured markdown
SELECT page, markdown FROM pdf.pages
WHERE file_name = 'sample_report.pdf'
ORDER BY page;

-- Search across all documents
SELECT file_name, page FROM pdf.pages
WHERE text LIKE '%machine learning%';

-- Find links in documents
SELECT file_name, page, links FROM pdf.pages
WHERE links LIKE '%linkedin%';

-- Pages with annotations (comments, highlights, etc.)
SELECT file_name, page, annotations FROM pdf.pages
WHERE json_length(annotations) > 0;

-- Pages with form fields
SELECT file_name, page, widgets FROM pdf.pages
WHERE json_length(widgets) > 0;

-- Find pages containing tables
SELECT file_name, page FROM pdf.pages
WHERE tables LIKE '%"header"%';

-- Document-level info
SELECT file_name, page_count, file_size, metadata
FROM pdf.documents
ORDER BY file_size DESC;

-- Documents with table of contents
SELECT file_name, toc FROM pdf.documents
WHERE json_length(toc) > 0;

-- Documents with embedded files
SELECT file_name, embedded_files FROM pdf.documents
WHERE json_length(embedded_files) > 0;
```

## Tables

### `pages`

Text, tables, images, links, annotations, and form fields extracted from PDF documents, one row per page. Generated by the `pdf-to-jsonl.py` converter script using PyMuPDF.

**Columns**

| Column | Type | Nullable | Description |
|--------|------|----------|-------------|
| `file_name` | Utf8 | false | File name of the source PDF (e.g. sample_report.pdf). |
| `path` | Utf8 | false | Absolute filesystem path to the source PDF. |
| `page` | Int64 | false | Page number within the PDF (1-indexed). |
| `page_count` | Int64 | false | Total number of pages in the document. |
| `text` | Utf8 | false | Full plain text content extracted from the page. |
| `markdown` | Utf8 | false | Structured markdown preserving headings, bold, and italic formatting. |
| `blocks` | Json | false | JSON array of text blocks with position (x0,y0,x1,y1), font name, size, bold, italic, and color. |
| `tables` | Json | false | JSON array of extracted tables with header row and data rows. |
| `images` | Json | false | JSON array of image references with width, height, and xref. |
| `links` | Json | false | JSON array of hyperlinks with URI, kind, and bounding box. |
| `annotations` | Json | false | JSON array of annotations (comments, highlights, stamps, etc.) with type, content, and position. |
| `widgets` | Json | false | JSON array of interactive form fields with name, type, value, and position. |

### `documents`

Per-document summary metadata including table of contents, embedded files, page labels, and file-level metadata. Generated by the `pdf-to-jsonl.py` converter script.

**Columns**

| Column | Type | Nullable | Description |
|--------|------|----------|-------------|
| `file_name` | Utf8 | false | File name of the source PDF (e.g. sample_report.pdf). |
| `path` | Utf8 | false | Absolute filesystem path to the source PDF. |
| `file_size` | Int64 | false | File size in bytes. |
| `page_count` | Int64 | false | Total number of pages in the document. |
| `metadata` | Json | true | PDF document metadata (author, title, subject, producer, creation date, etc.). |
| `toc` | Json | false | JSON array of table of contents entries with level, title, and page number. |
| `embedded_files` | Json | false | JSON array of embedded file attachments with name, description, size, and MIME type. |
| `page_labels` | Json | false | JSON array of page label definitions with start page, style, prefix, and start number. |

## Extraction details

| Feature | Method | Description |
|---------|--------|-------------|
| **Text** | `page.get_text("text")` | Full page text for SQL search and content retrieval. |
| **Markdown** | Block-level analysis | Headings sized by font size + bold, italic preserved, bullet points kept. |
| **Blocks** | `page.get_text("dict")` | Each text span with precise bounding box, font, size, bold/italic, color. 25+ text blocks per page. |
| **Tables** | `page.find_tables()` | Header row + data rows with bounding box. Empty array `[]` if no tables. |
| **Images** | `page.get_images()` | Image references with xref, width, height. Binary data not stored. |
| **Links** | `page.get_links()` | Hyperlinks with kind (uri/goto/launch), URI, and bounding box. |
| **Annotations** | `page.annots()` | Comments, highlights, underline, strikeout, stamps, etc. with type name, content, author, position. |
| **Widgets** | `page.widgets()` | Form fields including text fields, checkboxes, radio buttons, dropdowns, listboxes with name, type, value. |
| **TOC** | `doc.get_toc()` | Document outlines/bookmarks with level, title, and destination page. |
| **Embedded files** | `doc.embfile_*()` | Attached files with name, description, size, and MIME type. |
| **Page labels** | `doc.get_page_labels()` | Page numbering scheme (roman numerals, etc.). |
| **OCR** | `ocrmypdf --force-ocr` | Optional OCR pass for scanned/image-only PDFs. |

## Limitations

- The source reads from pre-converted JSONL files — re-run `pdf-to-jsonl.py` when PDFs change.
- Text extraction quality depends on the PDF format. PyMuPDF handles most PDF types robustly.
- Scanned PDFs (image-only, no text layer) will have empty `text` — use `--ocr` flag with OCRmyPDF installed.
- Table extraction uses PyMuPDF's built-in table detection — works well for bordered tables, may miss borderless ones.
- Image binary data is not stored in JSONL — only references (xref, dimensions).
- Annotation extraction covers visible annotations; hidden or empty annotations may be skipped.
- OCR requires `ocrmypdf` to be installed separately. The converter processes a temporary copy and leaves originals untouched.

## Source scope

- Reads JSONL files from `~/.coral/pdf/pages.jsonl` and `~/.coral/pdf/documents.jsonl`.
- Two tables: `pages` (per-page extraction) and `documents` (per-file summary).
- Provides read-only access to extracted PDF content and metadata.
- No required filters — all columns are queryable directly.
- 1 declared test query confirms the source is connected and pages are readable.
