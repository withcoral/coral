# Triage Labels

| Label in mattpocock/skills | Label in this repository | Meaning                                |
| -------------------------- | ------------------------ | -------------------------------------- |
| `needs-triage`             | `needs-triage`           | Maintainer must evaluate this issue    |
| `needs-info`               | `needs-info`             | Waiting for more information           |
| `ready-for-agent`          | `ready-for-agent`        | Fully specified and ready for an agent |
| `ready-for-human`          | `ready-for-human`        | Requires human implementation          |
| `wontfix`                  | `wontfix`                | Will not be done                       |

When a skill names a canonical triage role, use its mapped label from this
table.
