Coral Desktop is the graphical Coral app for macOS. Use it when you want the
Coral UI for sources, traces, schema exploration, and agent setup.

<Note>
  The first desktop package is a macOS DMG for Apple Silicon. Use the CLI
  install options when you only need terminal commands or a non-macOS install.
</Note>

## Install

1. Download `coral-desktop-mac-arm64.dmg` from the [Coral GitHub release assets](https://github.com/withcoral/coral/releases).
2. Open the DMG.
3. Drag `Coral.app` into Applications.
4. Open Coral from Applications.

If you drag the app into the system Applications folder, it is installed at:

```text
/Applications/Coral.app
```

If you drag it into your user Applications folder, it is installed at:

```text
~/Applications/Coral.app
```

## How the desktop app runs Coral

Coral Desktop bundles the Coral CLI inside the app. When the app starts, it
launches the bundled CLI as a local sidecar:

```shellscript
coral ui --no-open --port 0
```

The sidecar binds to a local loopback port and serves the Coral runtime that the
desktop UI talks to. You do not need a separate Homebrew or install-script CLI
install for the desktop UI to start.

This iteration only supports the bundled local sidecar. A future version will
also let the desktop app connect to a remote Coral CLI server instance.

## Connect an MCP client

Open **Settings** in Coral Desktop, then use **MCP clients** to connect a
supported agent client.

Coral Desktop currently supports:

- Codex
- Claude Code

Click **Connect** for the client you use. Coral Desktop writes the client's MCP
configuration through `add-mcp` and points the client at the bundled CLI inside
the installed app with:

```text
mcp-stdio
```

This means the agent launches Coral's MCP stdio server from the installed app
bundle when it needs Coral. It does not connect to the already-open Electron
window.

If you move or reinstall `Coral.app`, open Settings and click **Connect** again
so the MCP client points at the current app bundle.

## What is not included yet

- connecting the desktop app to a remote Coral server
- installing a terminal `coral` alias from the app
- testing MCP connections from the Settings page
- configuring Claude Desktop
- automatic updates
- Windows and Linux desktop installers
