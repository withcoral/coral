title: "Quickstart"
description: "Set up Coral in minutes: import a SourceSpec, add your first source, and start querying your data."
---

This tutorial gets you from a fresh [install](/getting-started/installation) of Coral to your first SQL query.

<Tip>
  Prefer the CLI experience? Run `coral onboard` for an interactive wizard that
  walks you through the whole setup described in this page.
</Tip>

## 1. Create a SourceSpec

```shellscript
mkdir -p /tmp/coral-quickstart
printf '{"id":1,"text":"hello"}\n{"id":2,"text":"world"}\n' > /tmp/coral-quickstart/messages.jsonl
cat > /tmp/coral-quickstart/messages.source.yaml <<'YAML'
spec_version: 1
kind: source
name: local_messages
interfaces:
  - id: messages
    type: file
    files:
      - ./messages.jsonl
    format:
      kind: jsonl
YAML
```

This defines a local JSONL file source. Active bundled sources, when present in your build, are listed with `coral source discover`; this branch only treats SourceSpec-backed entries as active bundled sources.

## 2. Add a source

```shellscript
coral source add --file /tmp/coral-quickstart/messages.source.yaml
```

Once connected, the source's data is available as SQL tables.

<Tip>
  For SourceSpecs with declared variables or secrets, Coral reads each input
  from an environment variable of the same name, or prompts when you pass
  `--interactive`.
</Tip>

## 3. Query your data

You can now query any connected source using SQL.

Use `information_schema.tables` to see all available tables:

```shellscript
coral sql "SELECT table_schema, table_name FROM information_schema.tables WHERE table_schema <> 'information_schema' ORDER BY 1, 2"
```

```shellscript
coral sql "
  SELECT id, text
  FROM local_messages.messages
  ORDER BY id
"
```
